# 物理裕度标定报告（margin calibration）

- 样本：54297（训练 38143 / 留出 16154，按 run 70/30 划分）
## 结论

- 原假设形式 margin = m₀ + k·κ·v² **被数据否决**（拟合 k = 0.000）：
  实测横向偏差与 κ·v² 无关，而是**随速度下降**（低速机动段大、高速稳态小）。
- 部署裕度 = margin.ts 的**速度分段表**（<5m/s: 1.0；5-10: 1.0→0.8；10-15: 0.8→0.4；≥15: 0.4）。
- 留出集覆盖率：拟合模型 96.3%；**部署速度表 95.2%**（目标 ≥95%）。

## 第二轮分析（2026-09-25，阶段 C 前置）：机动/稳态切分**被数据否决**

动机：B 的批量实证显示"低速预算 0.9~1.15m > 窄口车身余量 0.6~0.95m"，怀疑低速大偏差来自
"横移机动进行中"的样本；若能按机动/稳态分开建模，稳态预算可降到 0.3~0.5m 从而安全通过窄口。

切分定义：`ρ = |best.targetL − frenet.l|`（横移未完成量，m）；ρ ≤ 0.2m 记为稳态。
预测量分离能力（全库 84369 样本 / 116 runs；e = 车到上一帧轨迹的距离，m）：

| 切片 | 样本 | e p50 | e p95 |
|---|---|---|---|
| 稳态 ρ≤0.2m | 10773 | 0.011 | **0.728** |
| 机动 ρ>0.2m | 73596 | 0.022 | **0.793** |
| 机动 ρ>0.5m | 65411 | 0.024 | 0.802 |
| 机动 ρ>1.0m | 52430 | 0.026 | 0.827 |

按速度分层（e p95）：v 1-5：稳态 1.106 / 机动 1.157；v 5-10：0.902 / 0.912；
v 10-15：0.664 / 0.765；v 15-25：0.549 / 0.689；v 25-40：0.323 / 0.466。

另测预测量：相邻规划目标跳变 |ΔtargetL|（≤0.05m 组 p95=1.002，>0.5m 组 1.004）、
横向速率 |dl/ds|·v（≤0.2m/s 组 p95=0.973，>1.0m/s 组 0.996）——**均不分离 p95**。

结论：**p95 不随任何单一工况预测量下降**（各切片都在 0.95~1.05m）；p50 有分离
（稳态 0.011m vs 机动 0.02~0.10m）说明"典型跟踪很准"，但决定安全裕度的是尾部（5% 帧 ~1m），
其来源是**规划轨迹逐帧形状变化**（同目标、同速度下仍有 5% 帧偏离 ~1m），不是执行跟踪能力。

推论（写入阶段 C 计划）：裕度不能靠重标定收紧；要安全通过窄口，必须先把**轨迹形状稳定下来**
（阶段 C 收敛迭代 + 后续轨迹连续性工作），或在候选准入层面不选过窄缝隙。本报告的部署速度表
继续作为阶段 C 物理走廊的裕度。
